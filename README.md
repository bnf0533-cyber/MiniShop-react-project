# Mini Shop

## איך להריץ:
התקנת סיפריות
```
npm install
```
הרצה של הפרוייקט
```
npm run dev
```

איפה שהשתמשתי ב-Hooks ו-State:
- חיפוש ואינפוט: השתמשתי ב useState כדי לסנן את המוצרים לפי מה שמקלידים וב useRef בשביל שהעכבר יקפוץ לשדה החיפוש ישר כשנכנסים לאתר
- טעינת נתונים: כתבתי custom hook בשם useFetch שרץ עם useEffect מביא את המידע ומחזיר loading ו error הוא מביא את כל המוצרים לדף הבית ואת המוצר הספציפי לעמוד המוצר
- עמוד מוצר וניווט: שלפתי את ה id מהכתובת עם useParams ובכפתור חזרה השתמשתי ב-useNavigate
- מועדפים: מנוהל עם Zustand בחנות נפרדת עם שמירה ב localStorage (הוספה והסרה) ע"י persist
- דארק מוד: עשיתי עם Context  שמחזיק אם אנחנו ב light או dark ומשנה את זה בלחיצה מה Header
